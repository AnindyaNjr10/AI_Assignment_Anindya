# Customer Support Ticket Classification System

## 1. Project overview
A small machine-learning system that reads the text of a customer support ticket and predicts its
**category** (Login Issue, Application Error, Report, Account Update, Performance, Billing Issue).
It includes data cleaning, EDA, model training/evaluation, a command-line app, a Flask web app, and a
rule-based "suggested reply" (bonus task).

## 2. Problem statement
A company receives support requests through many channels. Manually sorting them is slow, so we
want to automatically predict the category of a new ticket from its description.

## 3. Technologies used
Python 3.x, pandas, NumPy, scikit-learn (TF-IDF, Logistic Regression), matplotlib, seaborn, joblib, Flask.

## 4. Dataset
* **Created by the author** (no external dataset). 208 raw rows, 6 categories, fields:
  `ticket_id, ticket_description, category, priority, status`.
* Generated by `src/generate_dataset.py` (descriptions written by hand; a few overlapping-vocabulary
  tickets, duplicates, messy text and missing values were added on purpose to practise cleaning).
* After cleaning: **200 tickets** (2 dropped for missing description, 6 duplicates removed).

## 5. Installation
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 6. Train the model
Run from the project root:
```bash
python src/train.py
```
This cleans the data, prints the EDA, compares 3 models, evaluates on a 20 % test set, saves
`model/ticket_classifier.joblib` and the charts in `screenshots/`.
(Optional) regenerate the dataset first: `python src/generate_dataset.py`.

## 7. Predict
```bash
python src/predict.py            # interactive command-line app
python src/predict.py --test     # runs 10 documented test tickets
```

## 8. Run the web app
```bash
python src/app.py
```
Open http://127.0.0.1:5000

## 9. Sample input / output
```
Enter Ticket Description:
> The application is taking too long to load.

Predicted Category: Performance
Confidence: 92.6%
Suggested Response: We are sorry for the slowness. Please try clearing your browser cache ...
```

## 10. Results (20 % hold-out test set, 40 tickets)
Accuracy 95 %, macro precision 0.955, macro recall 0.952, macro F1 0.950. Details in `report.pdf`.

## 11. AI tools used
Claude (Anthropic) was used to help draft the code, the dataset and the documentation. The author reviewed
and is responsible for the submission. No API keys or external AI APIs are used at run time (the bonus
replies are rule-based).
